# WFL-ASR-hhskt-ru

[English](README.md) | **Русский**

Русская модель разметки фонем для [WFL-ASR](https://github.com/MLo7Ghinsan/WFL-ASR/tree/refactor) (ветка refactor).
Размечает пение фонемами **без текста** или выравнивает заданную последовательность фонем.
На выходе HTK `.lab` в фонемсете hhskt, том же, что у
[hhskt_ru_phonemizer](https://github.com/Megageorgio/hhskt_ru_phonemizer).

![SOFA и WFL](images/sofa-vs-wfl.png)

## Скачать

[Релизы](https://github.com/Megageorgio/WFL-ASR-hhskt-ru/releases): `hhskt-ru-small.zip`, около 70 МБ. Внутри:

```
hhskt-ru-small.pt   веса (fp16)
config.yaml         конфиг модели
phonemes.txt        выходные метки
langs.txt           ru,0
```

## Использование

### mLabeler

Добавьте распакованную папку как модель WFL-ASR в [mLabeler](https://github.com/Megageorgio/mlabeler) и запустите авторазметку.

### WFL-ASR

Нужна ветка `refactor` WFL-ASR (проверено на коммите `8ea6559`) и её зависимости
(`librosa==0.11.0`: с более новой librosa ломается Viterbi-декодирование).

```bash
git clone -b refactor https://github.com/MLo7Ghinsan/WFL-ASR
cd hhskt-ru-small
python ../WFL-ASR/infer.py -i путь/к/wav -ckpt hhskt-ru-small.pt -c config.yaml -l 0
```

Запускайте из папки модели: WFL-ASR ищет `phonemes.txt` в `save_dir` из `config.yaml` (`.`) и при первом запуске
скачивает энкодер `openai/whisper-base` в `./encoder`.

- `.lab` пишутся рядом с `.wav` **и перезаписывают существующие**.
- Без текста модель сама распознаёт фонемы.
- Если рядом с `.wav` лежит `.txt` с тем же именем, модель выравнивает последовательность фонем из него
  (фонемы через пробел, из таблицы ниже).

## Фонемы

| | |
|---|---|
| гласные | `a` `i` `u` `e` `o` `y`, `ax` (в**о**да), `x` (пр**и**вет), `ex` (**э**фир) |
| согласные | `b` `v` `g` `d` `z` `k` `l` `m` `n` `p` `r` `s` `t` `f` `h` `sh` `ts` `zh` |
| мягкие согласные | `by` `vy` `gy` `dy` `zy` `ky` `ly` `my` `ny` `py` `ry` `sy` `ty` `fy` `hy` `shy` (щ) `ch` `j` (й) |
| прочее | `SP` тишина, `AP` вдох, `vf` vocal fry, `cl` смычка |

|---|---|

## SOFA или WFL?

Они решают разные задачи, поэтому на своём голосе стоит попробовать обе.

Пример на одной дорожке (около 3 минут, не участвовала в обучении), сравнение с ручной разметкой, слой фонем:

| | средняя ошибка границ | медиана | точнее 20 мс | фонем не совпало с ручной разметкой |
|---|---|---|---|---|
| WFL (без текста) | 5,4 мс | 3,1 мс | 96% | 147 |
| SOFA (с текстом) | 15,4 мс | 6,5 мс | 87% | 263 |

Это одна запись, а не замер на наборе данных: на другом голосе может оказаться наоборот.

- **WFL** слушает, что на самом деле спето. На скриншоте SOFA идёт по словарю
  (*никому* → `ny x k o m u`), а WFL слышит спетое `ny i k a m u` и ещё находит `SP` перед вдохом.
  Границы обычно точнее. Текст не нужен. Лучше всего работает на голосах, похожих на обучающие;
  на сильно непохожих чаще путает фонемы.
- **SOFA** нужен текст, и размечает она ровно то, что ей дали, со слоем слов. Надёжнее, когда
  произношение должно совпадать с текстом или голос не похож ни на что из обучающих данных.
